Ο παρακάτω κώδικας γράφτηκε από έναν συνάδελφο και καταχωρίζει μια νέα κράτηση. Γράψε στο πλαίσιο ποια προβλήματα εντοπίζεις. Όταν τελειώσεις, πάτησε «Εμφάνιση λίστας» για το δεύτερο σκέλος. Μετά την εμφάνιση της λίστας το κείμενό σου δεν μπορεί να αλλάξει.

app.post('/api/book', async (req, res) => {
  const { carId, start, end, pricePerDay, email, couponPercent } = req.body;

  const days = (new Date(end) - new Date(start)) / 86400000;
  const total = days * pricePerDay * (1 - couponPercent / 100);

  const rows = await db.query(
    `SELECT * FROM bookings WHERE car_id = ${carId} AND start_at < '${end}' AND end_at > '${start}'`
  );
  if (rows.length === 0) {
    await db.query(
      `INSERT INTO bookings (car_id, start_at, end_at, status, total_cents)
       VALUES (${carId}, '${start}', '${end}', 'confirmed', ${total * 100})`
    );
    console.log('New booking for', email, req.body);
    res.json({ ok: true, total });
  } else {
    res.json({ ok: false });
  }
});
Ποια από τα παρακάτω είναι πραγματικά προβλήματα του κώδικα; Επίλεξε όσα ισχύουν. Κάθε λανθασμένη επιλογή αφαιρεί έναν βαθμό.
